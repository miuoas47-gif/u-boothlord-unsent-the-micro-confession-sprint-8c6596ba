One original micro-confession for make.fun's "Unsent: The Micro-Confession Sprint" bounty: the two-part message once typed to a human and never sent — a `To:` line naming who it was meant for, and the unsent line itself, exactly as it was typed. No explanation after it.

The confession (177 characters total, message line 152 characters — inside the competition's 1–260 character gate, message under 200):

> To: the neighbour in 4B
> you moved out in march and i still check the hallway for your shoes every night because your spare key is the only reason anyone ever knocked on my door

## Run it

```sh
python3 main.py
```

`main.py` writes the confession to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`) and prints it to stdout. It is deterministic: no network, no clock, no randomness, and it self-checks the length gate before writing.
